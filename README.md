
# Linux Server Administration Lab

This repository documents my hands-on learning journey in Linux system administration, virtualization, networking, and server management.

## Project Objectives

- Install Ubuntu Linux using VirtualBox
- Learn essential Linux terminal commands
- Manage Linux users, groups, and permissions
- Configure SSH remote access
- Set up a basic Nginx web server
- Learn basic firewall and network configuration
- Document installation steps and troubleshooting
